## 화면 (로컬, mellow 테스트베드)

- 설정 → 콘텐츠 가이드: 기둥 5·좋은 예시 3·피할 예시 2·금지 문구 3·고정 해시태그·웹사이트 필수·사진 연출·템플릿·하단 문구·로고 업로드 저장 → 프로필 버전 4, 로고 미리보기 배경색 반영.
- 콘텐츠 편집 → 템플릿으로 디자인: 사진 게시물에 헤드라인 2줄·보조 문장 적용 → 미리보기에 합성 이미지, 원본 사진 기록.
- 발견·수정: 기존 `posts/:id/:action` 라우트가 `/template`을 먼저 받아 거부 → `templates/:postId`로 분리. 패널 입력 칸이 옆으로 흐르던 배치 수정.
- 제한: 자동화 도구의 한글 입력이 React 입력칸에 반영되지 않아 테스트는 입력 이벤트로 값을 넣었다(실제 키보드 입력은 일반 입력칸과 같다).
