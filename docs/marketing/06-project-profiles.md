# 초기 제품 프로필 초안

작성: 2026-09-25 · 최초 기획 초안. 이후 사용자가 지정한 5개 저장소를 분석해 기본 프로필·로고로 반영했다. 최신 설정과 Movy 분석은 [다섯 제품 기본 설정](10-product-setup.md)을 우선한다. 수동 검토 완료된 AI 입력은 아니다.

각 제품의 고객층·브랜드·현재 기능·가격·출시 상태는 운영자가 검토해야 한다. 코드 또는 기획에 있다는 사실과 현재 고객이 이용할 수 있다는 사실을 구분한다. 아래 캠페인·말투는 새 기획 제안이다.

## 공통 등록 항목

| 항목 | 기록 내용 |
| --- | --- |
| 정체성 | 제품명, 한 줄 설명, 공식 URL, 로고 |
| 고객과 목표 | 주요 고객, 해결하는 문제, 이번 캠페인의 행동 목표 |
| 제품 사실 | 기능별 설명, 근거 문서/페이지, 확인일, 검토 상태 |
| 변동 정보 | 가격, 무료 한도, 출시 국가·플랫폼, 확인일 |
| 언어·말투 | 기본 언어, 콘텐츠 언어, 예시 문구, 피할 표현 |
| 시각 자료 | 색상·서체·참고 이미지·실제 화면·허용된 자료 |
| 채널 | 실제 연결 계정, 기본 목적지, 채널별 운영 방식 |
| 운영 | 기본 시간대, 생성 한도, 검토·발행 설정 |

첫 AI 생성 전에 최소한 설명·핵심 기능·고객·언어·말투·확인된 소개 링크를 검토한다. 가격과 출시 정보는 미확인으로 둘 수 있지만 해당 주장은 생성하지 않는다.

## mellow

- 저장소: `~/projects/eun/mellow`
- 설명 초안: AI 친구와 예약된 음성 통화로 외국어 회화를 연습하고 표현을 복습하는 서비스.
- 근거: 기존 마케팅 정책, `docs/marketing/`, Nullge 회사 소개의 mellow 항목.
- 소개 URL: `https://www.mellowcall.com/` — 기존 회사 페이지에 등록된 주소. 실제 목적지와 CTA는 등록 시 확인.
- 콘텐츠 소재: 일상에서 말을 꺼내는 순간, 예약 통화, 대화 후 표현 복습.
- 제안 말투: 친근하고 구체적인 짧은 문장. 실제 친구 같은 대화 경험을 설명하되 AI임을 명확히 함.
- 피할 주장: 실제 원어민 교사, 실재 고객 후기 조작, 학습 효과 보장, 미확인 통화 다시듣기·요금·다운로드 가능 상태.
- 남은 검토: 최신 모바일 기능·가격·출시 범위·영어 콘텐츠 대상·현재 브랜드 자료.

첫 파일럿 제안: `하루의 이야기를 말로 꺼내기`. 소개형·상황형·표현형 초안을 각각 1개 만든다. 기존 8개 초안은 비교·이관 대상이며 현재 상태는 다시 조회한다.

## ClipIt

- 저장소: `~/projects/eun/clipit`
- 설명 초안: 긴 영상에서 AI가 하이라이트를 찾아 세로 클립을 만들고 제목·자막·템플릿을 편집하는 서비스.
- 근거: 저장소 `README.md`, `apps/marketing-video/README.md`, Nullge 회사 소개의 ClipIt 항목.
- 소개 URL: `https://clipit.studio/` — 기존 회사 페이지에 등록된 주소. 실제 목적지와 CTA는 등록 시 확인.
- 콘텐츠 소재: 긴 영상의 활용, 하이라이트 선택, 자막·제목·템플릿 편집, 실제 작업 화면.
- 제안 말투: 결과와 작업 과정을 짧게 보여주는 실용적인 문장.
- 피할 주장: 조회수·수익 보장, 측정하지 않은 시간 절감률, 모든 영상/플랫폼 지원, 등록하지 않은 가격·무료 한도.
- 남은 검토: 허용 입력 형식, 실제 사용자 흐름, 현재 요금·크레딧, SNS 계정, 최신 브랜드 자료.

첫 파일럿 제안: `긴 영상 한 편을 짧은 콘텐츠로`. 기능 소개·편집 과정·활용 상황 초안을 각각 1개 만든다. 기존 Remotion 홍보 영상은 사용할 수 있는 후보 자료이며 자동 가져오기나 새 렌더링을 이번 기획에서 실행하지 않는다.

## minimo

- 저장소: `~/projects/eun/desktop_pet` — 사용자 정정. 이름은 `minimo` 유지.
- 설명 초안: 화면 위를 걸어 다니며 대화하고, 허락받은 화면을 함께 봐주는 AI 데스크톱 펫.
- 근거: `README.md`, `docs/specs/minimo-branding.md`, `docs/verification.md`, AI CLI 제공자 설정.
- 콘텐츠 소재 제안: 작업 중 화면 위 펫, 단축키 대화, 허용을 받은 화면 보기, 이름·성격 고르기.
- 제안 말투: 작은 픽셀 동반자처럼 친근하고 간결하게.
- 피할 주장: 완전 오프라인·외부 전송 없음, AI 제공자 비용까지 무료, Windows·음성·모든 CLI 실사용 검증 완료, 다른 미니홈피 프로젝트의 기능.
- 남은 검토: 실제 다운로드·릴리스·지원 환경·AI 제공자 조건·공식 URL·SNS 계정.

처음 잘못 참조한 `~/projects/eun/minimo` 미니홈피와는 다른 제품이다. 로고는 `desktop_pet/apps/desktop/src-tauri/icons/icon.png`를 사용한다. 저장소의 시점별 문구와 실제 검증 기록을 구분한다.

## desk

- 저장소: `~/projects/eun/desk`
- 설명 초안: 뉴스 이슈를 정리해 기사와 팟캐스트로 전달하는 서비스.
- 근거: 현재 루트 `package.json`의 기사·이슈·팟캐스트 파이프라인, `docs/copy-guide.md`. 예전 `TODO.md`와 파이프라인 문서는 방향 참고용이다.
- 콘텐츠 소재 제안: 어떤 이슈를 다루는지, 기사·오디오 이용 방식, 제작 과정, 확인된 공개 에피소드 소개.
- 제안 말투: 명료하고 절제된 설명. 시점과 근거가 필요한 뉴스 주장은 별도 검토.
- 피할 주장: 기획 단계의 카드/마스코트/영상 기능을 현재 제공한다고 표현, 출처 없는 최신 사실, 생성 이미지를 실제 사건 장면으로 제시.
- 남은 검토: 정식 제품명, 현재 제공 형식·쇼 구성, 고객층, 공개 URL·에피소드, 이미지 정책·출처 표시 기준·계정.

첫 연동은 제품 소개와 확인된 콘텐츠의 수동 등록이다. 뉴스 수집·편집·팟캐스트 제작 파이프라인 자체를 Nullge 마케팅 서비스로 옮기지 않는다.

## 두 제품으로 먼저 검증하는 이유

mellow는 모바일 회화 서비스, ClipIt은 영상 제작 도구라 설명·소재·화면 활용이 다르다. 같은 생성 기능이 두 제품의 프로필을 바꿔 사용했을 때 자연스러운 콘텐츠를 만드는지 확인하기 좋다. minimo·desk를 추가할 때도 제품별 조건문이나 전용 배포 없이 등록할 수 있어야 한다.
