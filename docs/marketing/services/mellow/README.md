## 결정 사항

- 계정 이름: 글로벌 영어는 꼬리 없음, 한국어는 `_kr` (2026-10-06).
- Facebook 페이지는 서비스·언어권마다 하나. 한국용 "Mellow - AI 영어·외국어 회화"(10/10 이름 변경, 60일 재변경 불가), 영어용은 별도로 만든다 (2026-10-10).
- 광고 결제는 선불(충전한 만큼만 쓰임), 사업자 정보 등록 (2026-10-10).
- 첫 광고 목표는 트래픽(링크 클릭). 설치 목표는 SDK 도입 후 (2026-10-10).
- 광고 대상은 18세 이상. Google Play 신고(만 18세 이상)와 맞춘다 (2026-10-10).
- 영상 도구: Veo 대신 Higgsfield. 엠마는 얼굴 영상으로 만들지 않고 실제 앱 화면·목소리로만 등장 (2026-10-09).
- 노출 방식: 한 번에 크게 팔지 않고 얕게 여러 번. 10/18부터 2주는 게시물에 앱 이름·설치 권유 없이 상황·표현만, 단계적으로 드러낸다 (2026-10-10, 운영자 방향).
- 게시 경로: Buffer를 없애고 X·Threads·Instagram 모두 Console 직접 연결로 간다(공용 Meta 앱 "Nullge Marketing"). 직접 연결이라야 답글 이어 쓰기가 된다 (2026-10-10).
- 광고 소재 디자인: 어두운 배경 + 로고 + 흰색/초록 두 줄 헤드라인 + 실제 앱 화면 (2026-10-10, 운영자 선택).

## 지켜야 할 것

- 일반 게시물에 "AI로 제작한" 고지 문구를 넣지 않는다. **유료 광고에 AI로 만든 사람이 나오면 "가상 인물" 표시를 넣는다**(공정위 지침 2026-06-01, [common/paid-ads.md](../common/paid-ads.md)).
- 가짜 앱 화면, 지어낸 사용자 후기, 효과 주장 금지. 앱 화면은 Pencil V10 실제 화면 또는 앱 `en.ts` 실제 번역만.
- 공개 범위(2026-10-10 개발자 확인): **8개 언어(영어·일본어·중국어·스페인어·한국어·프랑스어·독일어·포르투갈어), AI 친구 19명**. 사이트·스토어도 이 숫자. 지난 대화 기억은 무료 사용자도 된다. 무료는 주 2회 5분, Premium은 월 300분·통화당 60분. 무료 체험은 없다.
- Console 채널 '다시 확인'·'다시 인증'은 연결 버전을 올려 그 채널의 예약이 모두 풀린다. 누른 뒤에는 예약을 다시 건다.
- AI 친구는 "AI 친구"라고 부르고 "당신"은 쓰지 않는다.
