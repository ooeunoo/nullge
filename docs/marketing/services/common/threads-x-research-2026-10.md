# Threads·X 글 형식 리서치 (2026-10-10)

목적: 후킹 첫 글 + 답글로 이어 쓰는 형식이 실제로 통하는지, 무엇을 지켜야 하는지 확인. 출처 대부분은 마케팅 블로그·툴 회사 글이라 수치는 검증되지 않았다. 방향만 쓰고 숫자는 우리 계정에서 직접 잰다.

## 대체로 일치하는 것

| 항목 | 내용 |
|---|---|
| 첫 1~2줄 | 스크롤을 멈추게 하는 건 첫 줄. 숫자·의외성·질문·공감 중 하나 |
| 답글로 이어 쓰기 | 첫 글은 궁금하게, 본론은 내 답글에 푸는 형식이 흔하고 권장됨 |
| 답글이 노출을 만든다 | 좋아요보다 답글과 대화 깊이. 이모지·"잘 보고 가요" 같은 짧은 답글은 거의 안 쳐줌 |
| 게시 후 30~60분 | 이때 달린 답글에 바로, 성의 있게 답하는 게 시간대보다 중요 |
| 링크 | X는 본문 링크가 노출을 깎는다는 보고가 많음 → 링크는 내 답글에. Threads는 의견이 갈림(직접 시험) |
| 주제 일관성 | 주제를 좁게, 요일 고정 시리즈를 4~6주 이상 |
| 피할 것 | "좋아요 누르면", 맞팔 열차(스하리), 같은 글 중복, 해시태그 5개 이상, 글 삭제 |
| 형식 섞기 | 글만 계속보다 이미지·캐러셀·짧은 영상 섞기 |

## 같은 분야 사례: 스픽 Threads `@speak_kr`

- 팔로워 10만, 소개 "대표님 허락 안 받고 걍 시작한 계정". 운영자 캐릭터(일하기 싫은 직장인)가 말하는 개인 계정 말투.
- Instagram은 카드·릴스로 표현을 정리하고, Threads는 사무실 일화·운영자 생각 속에 영어 표현을 끼워 넣는다(예: 연휴 후유증 → "I have the post-holiday blues").
- 반응이 큰 글은 표현 정리보다 유머 일화(만우절 글 좋아요 1.9천).
- 2026년엔 글 빈도가 낮음(3~8월에 몇 개).

## 확인 못 한 것

- 한국 X에서 영어·일본어 학습 계정이 크게 성장한 사례는 찾지 못했다. 한국 X 사용층은 덕질·트친 중심이라 Threads보다 반응이 약할 가능성.
- 접힘("더 보기") 기준 길이, 알고리즘 가중치 숫자.
