## 배운 것

- AI로 "가짜 사용자"를 만들면 입 모양·목소리·이야기가 어색해진다. 얼굴 없는 1인칭·뒷모습 장면 + 실제 앱 화면·목소리가 안전하다.
- 광고 자동 생성 도구(Ads Studio 등)는 레이아웃은 좋지만 가짜 후기·가짜 앱 화면을 넣는다. 결과물은 반드시 고쳐서 쓴다.
- 사람 영상(크리에이터 촬영)이 광고 성과는 가장 좋다. 한국 마이크로 크리에이터 1편 5~15만 원.
